# Planärende (kaava-asia)

För hantering av planärenden har tre funktioner lagts till i insticksprogrammet.

![](images/plan-matter-1.png)

## Skapa ett nytt planärende

Du kan lägga till ett nytt planärende på följande sätt:

1.  Börja med att trycka på knappen *Uusi kaava-asia*.

2.  Fyll i uppgifterna i formuläret som öppnas. Obligatoriska fält är markerade med en röd stjärna.

    ![](images/sv-plan-matter-1.png){ width="521" }

3.  Tryck slutligen på **OK**. Då sparas det nya planärendet i databasen och ställs in som aktivt. ***Ett planutkast som eventuellt har varit aktivt tidigare inaktiveras.***

## Redigera ett aktivt planärende

1.  Du kan redigera det planärende som är inställt som aktivt via knappen *Muokkaa kaava-asiaa*. Detta öppnar samma formulär som när du skapar ett nytt planärende.

2.  Komplettera information som saknas eller redigera redan sparade uppgifter i formuläret.

3.  Tryck på **OK** för att spara ändringarna. Redigeringen av planärendet inaktiverar inte det aktiva planutkastet.

## Öppna eller byta planärende

Insticksprogrammet tillåter endast att ett planärende är aktivt åt gången. Du kan öppna ett planärende genom att trycka på knappen *Avaa kaava-asia*.

1.  Detta öppnar ett fönster där alla sparade planärenden visas.

    ![](images/plan-matter-3.png){ width="589" }

2.  Välj det planärende i listan som du vill aktivera. Det valda planärendet markeras med blå färg, som i bilden ovan.

3.  Tryck slutligen på **OK**, varvid det valda planärendet blir aktivt och ***planutkastet inaktiveras***.

## Ta bort ett planärende

Rätten att ta bort ett planärende är reserverad endast för admin-användare. Om du har administratörsrättigheter till din organisations Arho-implementation kan du ta bort ett planärende genom att öppna tabellen för planärenden, välja raden för det önskade planärendet och trycka på **Delete**.
