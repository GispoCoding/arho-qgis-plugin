# QGIS

Arho används ovanpå QGIS. Det rekommenderas att använda LTR-versionen av QGIS (i skrivande stund version **QGIS 3.44**). Det är rekommenderat att använda en specifik användarprofil som skapats för Arho i QGIS. I denna profil sparas Arho-insticksprogrammet, databasanslutningen och dess tillhörande autentisering, samt senare information om de projektfiler som har använts i profilen.

Innan du använder Arho bör du försäkra dig om att din Arho-anslutning är öppen och att anslutningen till databasen fungerar. Om QGIS ber om användarnamn och lösenord för databasen är det något fel på anslutningen eller på åtgärderna vid ibruktagandet, eftersom QGIS borde hitta och använda inloggningsuppgifterna från den sparade autentiseringen.
