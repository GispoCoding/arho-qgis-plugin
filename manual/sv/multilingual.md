# Flerspråkig plan (Monikielinen kaava)

Arho gör det möjligt att utarbeta en flerspråkig plan. I Arhos inställningar kan användaren ställa in planens huvudspråk och övriga språk.

![](images/multilingual-1.png)

Språk läggs till via det gröna plustecknet och tas bort via den röda papperskorgen. Det går att välja mellan de sex språk som stöds av Ryhti.

![](images/multilingual-2.png)

När planen har mer än ett språk får de fält där text matas in ytterligare textfält. Detta gör det möjligt att mata in information på olika språk samtidigt.

Om avsikten ändå är att först utarbeta planen på ett språk och översätta den först i slutskedet, kan det vara lättare för användaren att dölja fälten för de övriga språken. Detta görs i inställningarna genom att välja *Näytä vain pääkieli*.

![](images/multilingual-3.png)

Fält som hämtas från kodverk får inte extra fält för olika språk, eftersom deras flerspråkiga värden fås direkt från kodverken. Inställningen *Koodiarvojen esityskieli* definierar på vilket språk värdena visas i användargränssnittet.
