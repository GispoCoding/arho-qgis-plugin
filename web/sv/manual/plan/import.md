# Importera planutkast

Med funktionen *Tuo kaavasuunnitelma* kan en JSON-fil i Ryhti-format importeras till Arhos databas, till exempel en säkerhetskopia tagen från Arho eller en JSON-fil som laddats ned från något annat planläggningsprogram. Verktyget ersätter den tidigare versionen av det importerade planutkastet, så verktyget kan inte användas för att göra kopior av samma planutkast i databasen.

1.  Välj den fil du vill importera i fältet *Kaavan JSON*.
2.  Ge planutkastet ett namn (detta namn överförs inte till Ryhti).
3.  Tryck slutligen på **OK**.
