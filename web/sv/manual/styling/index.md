# Visualiseringar

I Arho används regelbaserade visualiseringar. Syftet med dessa är att planbestämmelsernas innehåll ska styra hur objektet ser ut på kartan. Arho använder QML-filer för visualiseringarna, och visualiseringar som gjorts i ett QGIS-projekt påverkar inte Arhos planvisualiseringar.

I Arho-insticksprogrammet finns färdiga visualiseringar implementerade för landskapsplaner och generalplaner. Användaren kan skapa egna regelbaserade visualiseringar och ta dem i bruk via Arhos inställningar.
