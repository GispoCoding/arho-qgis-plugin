# Fel vid gränssnittsanrop (Rajapintakutsujen virheet)

Vid vissa åtgärder, som när en plan eller ett planärende valideras eller när en JSON-fil skapas, anropar Arho ett gränssnitt. Ibland orsakar anropet ett fel. Olika typer av fel och vad de betyder har samlats i ett separat dokument (på finska): [Rajapintakutsujen virheet](https://docs.google.com/document/d/1T9LZ1pFNRtw5uU8_HKtP0r7fxilqV-174JXPp6u1-lg/edit?usp=sharing).
