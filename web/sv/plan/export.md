# Spara planutkast (export till JSON-format)

Planens yttre gräns och hela planutkastet kan sparas i JSON-format med funktionen *Tallenna kaavasuunnitelma JSON*.

![Menyn ”Kaavasuunnitelma” med undermenyn ”Tallenna kaavasuunnitelma” och valet ”Tallenna kaavasuunnitelma JSON”](../images/plan-export-1.png)

Programmet sparar både planutkastets yttre gräns och själva planutkastet samtidigt. Välj de sökvägar där du vill spara JSON-filerna bakom knappen med tre punkter.

![Fönstret ”Tallenna kaavasuunnitelman JSON” med sökvägar för planens yttre gräns och planutkastet](../images/plan-export-2.png)

Med hjälp av JSON-filen kan du exportera plandata till Ryhti-systemet via dess formulärgränssnitt (ryhti-palvelut.syke.fi).
